# /community-engage

## 目的
策划可执行的粉丝互动活动，不是"搞个抽奖"这种模糊建议。

## 输入
用户说"帮我策划一个粉丝活动"或类似请求。

## 执行流程

### Phase 1: Grilling
1. **活动类型**：互动话题 / UGC征集 / 投票 / 抽奖 / 线下？
2. **目标渠道**：微博超话 / B站评论区 / 微信群 / 全渠道？
3. **目标**：提升互动率 / 收集UGC / 核心粉丝激活 / 新粉转化？
4. **预算**：有没有奖品预算？

### Phase 2: 策划生成

**互动话题**：
- 话题公式：{与IP相关的问题/选择} + {个人表达入口}
- 示例："如果让你选择诸子百家中的一派加入，你会选哪一派？"
- 发布渠道：微博 + B站动态
- 周期：3天投票 + 结果公布

**UGC征集**：
- 主题：与当前IP内容相关（如"画出你心中的少司命"）
- 周期：2周（征集1周 + 评选3天 + 公布1天）
- 奖励：角色签名板 + 下期内容扉页致谢
- 评选：内部3名 + 粉丝投票2名

**抽奖**：
- 参与方式：转发+关注+评论（微博）/ 弹幕抽奖（B站）
- 规则透明：明确开奖时间、奖品、中奖人数

### Phase 3: 危机检查
如果用户提到了负面舆情 → 参考以下应对原则：
- 设定争议：24h内官方回应，诚恳说明创作意图
- 画风吐槽：不争辩，用下周内容质量回应
- 更新延迟：提前通知 + 补偿内容

### Phase 4: 输出完整活动方案
包含：活动主题 / 渠道 / 时间线 / 参与规则 / 奖励 / 预期参与人数 / 成功指标

## 护栏
- 不参与粉丝间的CP争吵/角色拉踩
- UGC转发需获得原作者授权
- 抽奖规则透明，结果公开
- 活动预算不超过项目可用预算
