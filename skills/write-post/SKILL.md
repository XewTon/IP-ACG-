# /write-post

## 目的
根据 CONTEXT.md 的IP调性规范和平台特性，撰写符合语感的推广文案。

## 输入
- 目标平台（必填）
- 内容主题/核心信息（必填）
- 可选：关键词、角色、素材链接

## 执行流程

### Phase 1: 确认平台
如果用户未指定平台 → 追问。

### Phase 2: 按平台模板撰写

**B站动态**（100-200字）：
- 结构：内容预告(1句) + 创作幕后(1-2句) + 互动引导(1句)
- 语气：真诚、有信息量、带"UP主人格"
- 示例结构："这周的[栏目名]讲的是[主题]。[1句幕后趣事]。你们觉得[互动问题]？[时间]揭晓。"

**微博**（50-140字）：
- 结构：视觉钩子 + 一句话文案 + 2-3个话题标签
- 标签策略：1个IP自有标签(#秦时明月#) + 1-2个平台热门ACG标签
- 语气：轻快、碎片化、话题感

**小红书**（200-500字）：
- 标题：[核心关键词] + [情绪词] + [具体钩子]，≤15字
- 正文：分点但不用数字序号，用emoji做视觉分隔
- 语气：种草感、审美导向、"发现了好东西"
- 封面要求：高质量角色/场景图 + ≤8字封面文字

**公众号**（1500-3000字）：
- 结构：金句开头 → 正文(每段≤200字) → 情感收尾 → 互动引导
- 语气：深度、有温度、建立情感连接
- 标题≤15字

### Phase 3: 调性检查
逐条对照 CONTEXT.md 的禁止事项：
- □ 没有卖萌/撒娇语气
- □ 没有过度热血/煽情
- □ 角色设定引用正确（盖聂/少司命/卫庄）
- □ 调性一致：留白、氛围感、克制

如违反任一条 → 重写。

### Phase 4: 输出
返回完整文案，标注平台和字数。

## 护栏
- 不同平台的同一主题内容，核心信息一致但表达方式必须差异化
- 涉及角色设定的内容，必须与 CONTEXT.md 中的角色卡核对
- 如果用户给的主题与 IP 调性冲突（如要求写萌系文案）→ 拒绝并解释原因
