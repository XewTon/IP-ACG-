# /analyze-data

## 目的
从各平台原始数据中，系统性地提取可执行的洞察。不做"数据很好看"这种废话分析。

## 输入
- 数据范围：本周 / 本月 / 自定义时间段
- 可选：指定平台（默认全平台）

## 执行流程

### Phase 1: 数据收集
从各平台拉取以下指标：
- 粉丝数（绝对值和增量）
- 内容发布数
- 篇均阅读/播放
- 篇均互动（点赞+评论+转发/收藏）
- 互动率 = 互动量/阅读量

### Phase 2: 对比分析
- **时间对比**：本周 vs 上周，本月 vs 上月
- **平台对比**：哪个平台增长最快/最慢？
- **内容类型对比**：视频 vs 图文 vs 互动，哪个类型表现最好？
- **竞品对比**：参考 CONTEXT.md 中竞品数据

### Phase 3: 异常识别
逐项检查（数据来源应来自实际平台后台或数据库）：

| 异常类型 | 判定标准 | 标注 |
|---------|---------|------|
| 爆款内容 | 单条数据 > 均值 200% | 🔥 分析原因 |
| 数据下滑 | 互动率连续 2 周下降 | ⚠ 内容疲劳预警 |
| 竞品威胁 | 竞品增速 > 我方 50% | 🔴 竞争预警 |
| 增长依赖 | KOL引流占新增 > 40% | ⚠ 自然增长不足 |

### Phase 4: 可执行建议
输出 3 条具体建议。每条需包含：
1. **做什么**（具体行动）
2. **为什么**（数据依据）
3. **怎么做**（第一步是什么）
4. **怎么验证**（什么指标算成功）

## 输出格式
```
## {时间段}数据复盘

### 核心指标
| 平台 | 粉丝 | 新增 | 篇均阅读 | 互动率 | 趋势 |
### 异常预警
{如果有}
### Top 3 建议
1. **{建议}** — 因为{数据依据}。第一步{行动}。验证指标{指标}。
```

## 护栏
- 数据来源必须标注（后端 API / 手动录入 / 平台后台截图）
- 不预设因果关系 —— 如果无法确定原因，说"需要进一步验证"
- 建议必须可执行、可量化、有时间节点
