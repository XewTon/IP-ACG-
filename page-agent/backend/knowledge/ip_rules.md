# 九歌 · IP 规范与禁用表达

## 视觉规范
- 水墨笔触为主（晕染+留白），日系造型仅用于面部比例参考
- 黑白为主色调，朱砂红仅用于关键视觉焦点
- 外包参考图≤5张精确对标，禁止「广而全」

## 文案风格
- 沈砚：说话简短，从不使用语气词和网络用语
- 林疏影：优雅克制，偶尔流露冷幽默
- 老白：市井俚语 + 半真半假的调侃
- 禁止卖萌 / 撒娇 / 热血 / 煽情语气

## 禁用表达
- ❌ 「啊啊啊好帅」类粉丝站语气
- ❌ 角色使用现代网络用语（yyds、绝绝子等）
- ❌ 过度解释世界观设定（保持神秘感，留白）
- ❌ 角色间 CP 拉踩或过度营业

## 禁止事项
- 不参与粉丝间角色拉踩
- 不泄露未公开设定
- 不在竞品重大发布日抢发同类型内容
