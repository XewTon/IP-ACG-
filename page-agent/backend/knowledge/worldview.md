# 九歌 / 墨迹 · 世界观与时间线

## 定位
东方幻想 × 神秘学 × 都市传说 × 年轻人成长。
调性：克制的东方美学 —— 留白、氛围感、不卖萌、不热血、不煽情。
视觉：水墨笔触 + 现代都市质感，黑白为主 + 朱砂红点缀 + 暗金提示。

## 核心规则
- **墨痕**：以墨为媒介感知世界真相的能力痕迹。
- **墨客**：能感知并记录墨痕的人。
- **墨客协会**：唐代成立，近代转入地下，负责整理与保密。

## 时间线
1. 远古：墨痕首次出现
2. 唐代：墨客协会成立
3. 近代：协会转入地下
4. 2025·春：沈砚在古籍部发现第一道墨痕 —— 故事开始

## 关键场景
- 图书馆古籍部（触发点）
- 南锣鼓巷疏影阁（林疏影据点）
- 潘家园地下市场（老白情报枢纽）
